# Phase 2G - shared Ridge forest

- Ridge career events, test runs and quick races use the same P11 oak/sycamore forest in the shared road runtime. Existing 2,953 tree placements now use textured bark, alpha foliage with subtle backlighting, three mesh detail levels and eight-view distant imposters. Wind deforms color and shadow geometry together and stops with reduced motion. Sport v5 physics, steering/input, route support/colliders, products, rewards and saves are unchanged.
- Added 2,562 deterministic fern/grass/branch placements and 95 rocks outside the road/runoff, with the overlook left clear. The original terrain vertices receive gravel-to-leaf/soil shading. Sparse depth-tested shafts and hollow mist appear on High/Ultra; existing headlights and markers remain at night. Compact instance batches cap the forest at 20 batches, with shorter distance and ground-cover budgets on Low/Medium. The original forest remains a working fallback after optional asset errors or a 30-second load timeout; `&forest=off` is the comparison switch.
- The package adds 25 existing assets (66,822,217 bytes). Models' original PNG master references are answered locally and every material is rebound to shipped compressed KTX2 maps, preventing hundreds of MB of duplicate downloads or missing hosted files. Authored assets remain unchanged. The 4K foliage atlases were originally resampled from 1254px source images; this integration does not claim native 4K detail. All owned instance buffers, geometry, materials and textures are released on exit.
- Typecheck, 372 tests and the production build pass. Browser checks cover day/night driving, all four quality settings, reduced motion, missing optional files and the comparison switch, with no shader errors or missing package downloads. Three complete Ridge career events use an isolated copy of the previously earned test save and real fixed-step pedal/steering input, preserving all five equipped products. Shared Harbor/Express/Ridge/Chapter 01 contact-shadow regression checks pass. Camera-only visual fixtures inspect bark, the forest road and the overlook without changing physics/race state. See `PHASE-2G-VALIDATION.json` for exact source/package hashes and evidence limits; `scripts/verify-phase2g.mjs` accepts BASE_URL and EVIDENCE_DIR.
- Sequential 1440p High four-car Ridge samples: 12.45 -> 9.14 ms average, 35.5 -> 17.7 ms p99, median draws 1,308 -> 1,134. This short local sample does not clear the inherited sustained-performance HOLD. Next is 2H surface textures, then the final Phase 2 benchmark criterion.
