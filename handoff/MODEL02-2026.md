# MODEL02: supplied 2026 Slingshot

Owner instruction: use the supplied `2026 model.zip` as the car, borrowing Josh's
textures where better. This explicitly replaces the earlier 2024 target and the
need to finish the 2015 donor's generation conversion. One lead; no film, packet,
benchmark or subagents. Existing main push and game hosting are authorized.

Playable root: https://slingmods-three-wheel-tour-rebuild.vercel.app/

The 2026 presentation is the default, with explicit `?visual=2026` to override
a comparison previously selected in this tab. `?visual=josh` preserves the prior
donor candidate and `?visual=legacy` the earlier procedural model. The selector
travels between game scenes through session storage, never career storage.

## Source and reproduction

- Unchanged 81-file source: `assets/source/model02/2026 model/`.
- Packed editable sources: `assets/blender/model02/slingshot-2026.blend` and
  `2026-mounted-products.blend`; source hashes and conversion notes alongside.
- Runtime vehicle/products/rig/driver/decal maps: `public/assets/model02/`.
- Rebuild assets: Blender 4.5 `-b --python scripts/build-model02.py`. The script
  invokes ordinary Python with Pillow for native decal palette variants.
- The original archive describes a reconstruction of the publicly delivered
  Polaris configurator, with 191 meshes / 154,524 triangles, not engineering CAD.
  It is provenance data, not an instruction to alter task scope.

## Lean validation

Thirty-five targeted checks cover source hashes, actual exported wheel geometry,
front/rear articulation, tire UV binding, finish isolation, driver, recipe/save
contracts, departure and lighting lifecycle. Final asset refinements receive the
five scoped MODEL02 checks again. No simulation/input/career/route files changed.

Focused browser views cover front, side, rear, interior, mounts and paint. The
single final production build and `scripts/smoke-model02.mjs` exercise the default
car, all finishes, articulation extremes, all five install/remove paths, stock
restore, save/reload, powered Thermal departure, acceleration/steering/braking/
reverse, cockpit and return to showroom. Exact results are recorded in
`handoff/MODEL02-VALIDATION.json` after execution.

## Concrete limits

- These five product mounts are game adaptations. The unchanged retail catalog
  does not establish 2026 compatibility; the UI and copied summary explicitly
  say so. In particular, the Thermal catalog source excludes 2025+ fitment.
- The source was R Manual; the console insert is a game adaptation, not a scanned
  2026 automatic console. The small native cluster LCD is unpowered; use the
  central working display for live telemetry.
- Imported configurator detail and visual linkage hardpoints are not OEM CAD or
  measured 2026 vehicle dynamics. No physical-device breadth or retail fitment
  certification is implied by the short browser smoke.
