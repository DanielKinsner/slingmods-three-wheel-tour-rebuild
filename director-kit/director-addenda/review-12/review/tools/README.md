These scripts document Astra's independent read-only review. They are NOT patches to the game and should not replace the project's installed compiler/test workflow. Paths reflect Astra's container, and reproducing them elsewhere requires changing input/output paths and providing the Review11/Review12 archives and the global TypeScript module. Run the local project's normal installed test/build tooling for production acceptance.

`inspect-review12.py` verifies manifest/assets/protected files and recalculates supplied performance data; it does not run the game or independently benchmark hardware. `ts-loader.mjs` was used solely to execute the61 self-contained tests without installing dependencies. The initial uncorrected-harness JSON-import error is retained in the evidence and is not a submitted-game defect.
