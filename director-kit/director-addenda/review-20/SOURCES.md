## Asset-use constraints
Generated reference images contain invented lighting, scene details, vehicle geometry and UI values. Do not trace those as OEM CAD, product instructions, real fitment, real performance data, exact map geography or a navigation product. Use existing authenticated project logos rather than generated lettering. The owner-supplied room photographs establish set identity; they do not replace current vehicle/source research.

Do not publish source photos or reference art indiscriminately in the game asset directory. Include only the deliberately produced, provenance-recorded artwork required by the runtime. Existing source/evidence may be in a public repository; this kit does not authorize changing visibility or disclosing credentials/personal material.
