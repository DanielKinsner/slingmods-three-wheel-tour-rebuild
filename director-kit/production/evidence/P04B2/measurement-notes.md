# Measurement boundaries

Scored runs are the five directories prefixed scored-. They use the final frozen implementation, a fresh headless Chromium process/context for each configuration, standard quality, DPR 1, ordinary virtual controller input, production buffer settings and no video. Each context completes two full valid laps with a native immediate Retry. Driver/OS shader caches were not cleared; unrelated desktop/OS activity was not controlled. Agent-driven renders and other tests were not run concurrently with these trials.

The logger stores bounded native RAF timestamps and adjacent intervals, CPU frame/render-submission durations, program/light-slot state, phase/attempt, ticks and observer cost. It makes no storage calls, GPU readback or asset scans in its hot loop. The controller agent uses only lightweight telemetry. Its per-frame CPU cost is included separately. Awaiting completion uses a small Playwright array-length predicate; this is still automated observation, not a claim of zero overhead.

The first row in each final run has interval 0 because no preceding RAF exists. Early preserved runs mixed the first RAF timestamp with performance.now and contain one invalid negative ready-state interval. This was corrected without changing subsequent samples, simulation timing or the render path. Historical rows are not edited or silently removed. Their all-frame totals include that invalid first value and must not be used as a precise loading duration; racing-phase statistics remain separate. Final scored runs use only RAF-to-RAF differences after the initial sentinel.

No gap was removed from a racing trace. Reports include all-phase maxima/outliers as well as racing-only metrics. Clamped catch-up time is the sum of intervals beyond the retained 100 ms session-frame cap; no simulation catch-up policy was changed. Source load time measures Harbor module entry through readiness, not browser process launch or earlier JS network/parse time. Explicit preparation stages include texture initialization, async compile, first all-mesh/shadow render and loading-only synchronization.

The separate video-final run records actual elapsed time with Playwright. Its raw intervals and recorder status are retained separately from scored results. The delivered continuous 25-second segment is silent. Controlled-clock verification is used only for deterministic cosmetic on/off physics and labeled still poses; it is not offered as real-time performance proof.
