# Rear authoring and reference boundary

The existing P03A2 Blender source was opened for local rear surgery. No earlier vehicle generation chain was rerun. Current source is assets/blender/vehicles/slingshot-p04a1.blend. The 687 retained evaluated source objects keep position/triangle/UV bytes, transforms and materials within the same Blender process. Repeated no-edit loads exposed Boolean triangulation/index ordering in the old console; that was not treated as permission to change the cockpit.

Reproduction from the root: run the installed Blender4.5.2 background executable with --python scripts/vehicle_p04a1_build.py, then run `python scripts/vehicle_p04a1_preserve_export.py` using existing numpy/scipy. The first step loads preserved slingshot-p03a2.blend and the rig JSON. It needs the included source-inventory.json for the component allowlist. The second step copies exact accepted GLB attributes/material definitions for unaffected nodes and retains exact old body-polymer attributes while removing only the7148 triangles corresponding to the removed rear walls/undertrays. Both directions of retained vertex membership match at zero positional difference. The old GLB is included as an authoring/comparison dependency. Original texture images are deduplicated by content; unused buffer bytes increase the file, not rendered triangles. No external asset service is called.

Final runtime uses rear_arm_visual, belt_visual, rear_axle_visual, rear_caliper_visual, shock_body_visual, shock_piston_visual and shock_spring_visual. The separately batched rear_pulley_visual is a child of the original spinning wheel. The fixed upper brackets now reach into the retained deck and cross-pins bridge both shock eyes and the chassis arm pivot. Storage is closed hollow left/right construction, with a stepped right recess around the mechanism and an open central wheel corridor. Access surfaces are fixed, not usable luggage doors.

Primary reference: [2024 Polaris manual](https://publications.polaris.com/owner/owners-manuals/9941119_R04/0000886646.xml?onepage=true), sections3.3.12/3.3.17, describes compartments behind each seat accessed by tilting the seatback. The artist inspected those illustrations and exact-year model images for right-side suspension/belt handedness. The lead re-read the manual; the exact-year marketing page returned403 on the lead retry. Reference targets and access history are in the supplied director REFERENCES.md. No photographs are licensed as game textures. Precise shock/pivot/storage dimensions remain photo-informed author estimates, not OEM CAD certification.

Authoring source iteration: geometry01 fixed the actual firewall overlap but the connection audit found upper brackets6–8mm short of the deck and no eye cross-pin. Geometry02 added pins, chassis support and bracket reach. A separate export-only correction isolates the new pulley UV layout and restores exact accepted buffers. No third geometry polish pass was performed.

Validation uses actual exported BVH triangles, all supported samples and all distinct recorded-lap hub heights with quarter spins, plus a conservative continuous swept tire envelope. The envelope test is deliberately stronger than a simple overlap allegation: every actual fixed triangle is separated from the whole enclosing swept box. Moving-link clearance remains a sampled mesh test; no continuous OEM articulation certification is claimed.
