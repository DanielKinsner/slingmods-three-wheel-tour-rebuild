# P06B water presentation repair

Benchmark03's close dock view showed large regular diamond-shaped reflections. The old single12m normal tiling made the flat surface read as a repeated material sheet. Its finite waterplane edge was also visible in the overview; geometry authoring must extend that presentation boundary. Shader work alone cannot hide a finite mesh boundary.

The new `src/presentation/harbor-water.ts` reuses the authored water normal map twice in independent wind-oriented world-metre coordinates:6x3.5m broad ripples and1.3x0.9m fine ripples. Slope weights0.21 and0.065 suppress the former exaggerated diamond response. Separate small UV drift velocities animate the existing texture; no noise texture, flow render target or per-frame allocation is required. The world coordinate is calculated after instancing/batching, so all cells agree on the surface. The existing outdoor PMREM supplies reflection. No planar scene reflection, refraction, hull wake simulation, extra draw pass or new light is claimed.

Diffuse color moves from restrained blue-green at the actual straight quay x=-28m to a darker deep-water blue over1.5–65m. This is a documented visual depth proxy, not bathymetry; it does not infer depths at the opposite authored shoreline. Roughness0.17 and metalness0 replace the previous metal-like response; normal-incidence specular reflectance0.02037 corresponds approximately to air/water IOR1.333, with the installed standard BRDF supplying the grazing-angle increase.

The stable material program key does not include animation time. Uniform updates do not increment material versions or request shader recompilation. Disposal restores the original material callbacks/scalars rather than disposing shared textures owned by the scene loader. Two focused CPU tests check stable shader key/material versions across time updates, finite clock values, retained normal texture identity and reversible material ownership. TypeScript passes. These do not replace actual GPU shader compilation, runtime water images or wall-clock profiling.
