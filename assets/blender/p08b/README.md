# P08B signature art: editable source and runtime contract

Rebuild from the repository root with background Blender 4.5.2:

```powershell
& .tools/blender-4.5.2-windows-x64/blender.exe --background --python scripts/build-p08b-art.py
& .tools/blender-4.5.2-windows-x64/blender.exe --background --python scripts/verify-p08b-art.py
```

Blender may be installed elsewhere; use the discovered executable. The scripts resolve every asset path from their own repository location. The authoring script loads the original P04A1 source read-only and writes only these new P08B sources/runtime assets. All source image dependencies are packed. Existing source and GLB bytes remain unchanged.

## Critique, repairs and limits

The first local room proof exposed rotated logo UVs, a camera-relative left/right lift error, and a missing door-parent matrix update. Each was repaired in source and re-exported; final matched browser proof is under `P08B/art/runtime`. The neutral source-only initial images had unresolved original source image paths and are not used to certify appearance; actual GLB before/after browser views are the comparison evidence. The new source repairs and packs those paths.

The console's eight boundary edges belong to the existing recessed pocket and remain; no blanket cavity fill or black patch was used. Genuine wheel wells, front vent openings, hood inlet and open cockpit remain. New physical rotor edge volumes and closed lug ends resolve measured zero-thickness/uncapped hardware. A source verification compares both world-space vertices and topology for every original object and rejects changes outside the named repair allowlist.

No final OEM fidelity/G3/G4/hardware approval is claimed. The original rear suspension still follows the existing vertical-raycast visual approximation. Room dimensions, bags, exhaust hidden routing and wing brackets are visually researched approximations, not manufacturing or fitment measurements. The standalone art proof uses stronger neutral lights than the integrated customer showroom and is not a performance run. Its wheel travel poses are diagnostic geometry poses with explicit values, not tire-ground/physics evidence.
